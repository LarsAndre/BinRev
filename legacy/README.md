# Archived implementations

`quartz-site/` is the previous Quartz implementation, including its configuration,
package manifest, type declarations, and upstream documentation. It is retained
for reference and is outside the active Astro build and deployment.

`astro-global.css` is an unused earlier Astro stylesheet. The active stylesheet
is `src/styles/site.css`.

For the current website, start with the repository README and `docs/authoring.md`.
